# PRD: PRISM-INSIGHT TUI - 대화형 주식 AI 분석 도구

## 문서 정보
- **문서 버전**: 1.0.0
- **작성일**: 2025-11-09
- **제품명**: PRISM-INSIGHT TUI (Text User Interface)
- **프로젝트 코드명**: Stock AI Review TUI

---

## 1. 제품 개요

### 1.1 제품 설명
PRISM-INSIGHT TUI는 콘솔 환경에서 실행되는 대화형 주식 AI 분석 도구입니다. 사용자가 주식 코드를 입력하면 12개의 전문화된 AI 에이전트가 협업하여 실시간으로 종합 분석을 수행하고, Claude Code와 유사한 직관적인 인터페이스로 결과를 제공합니다.

### 1.2 제품 비전
"개발자와 파워유저를 위한 터미널 네이티브 주식 분석 환경 제공"

### 1.3 핵심 가치 제안
- ✅ **즉시성**: PDF/텔레그램 없이 콘솔에서 즉시 분석 결과 확인
- ✅ **대화형**: 사용자가 원하는 만큼 종목 분석 반복
- ✅ **전문성**: 12개 AI 에이전트(GPT-5, Claude 4.1)의 협업 분석
- ✅ **효율성**: 기존 핵심 기능 100% 활용, 불필요한 출력 제거
- ✅ **확장성**: 기존 코드 수정 없이 독립 모듈로 동작

## 2. 목표 사용자

### 2.1 주요 페르소나

**페르소나 1: 테크 투자자 (Tech-Savvy Investor)**
- 특징: CLI 도구 선호, 빠른 의사결정, 멀티태스킹
- 니즈: 터미널에서 코딩하면서 주식 분석 병행
- 시나리오: "삼성전자(005930) 분석 → 결과 확인 → SK하이닉스(000660) 추가 분석"

**페르소나 2: 퀀트 개발자 (Quant Developer)**
- 특징: 자동화 선호, 스크립트 통합 활용
- 니즈: 분석 결과를 파이프라인으로 연결
- 시나리오: "급등주 리스트에서 종목 하나씩 TUI로 상세 분석"

**페르소나 3: 데이터 분석가 (Data Analyst)**
- 특징: 보고서 작성 필요, 체계적 정보 수집
- 니즈: 분석 → 검토 → 투자 보고서 저장
- 시나리오: "여러 종목 분석 후 필요한 것만 보고서로 저장"

## 3. 사용자 스토리

### Epic 1: 대화형 분석 세션
```
AS A 주식 투자자
I WANT 터미널에서 주식 코드를 입력하여 AI 분석을 받고
SO THAT 별도 앱 전환 없이 빠르게 투자 판단 가능
```

**User Stories:**
- US-001: 사용자는 프로그램 시작 시 환영 메시지와 명령어 안내를 본다
- US-002: 사용자는 주식 코드(예: 005930) 또는 종목명(예: 삼성전자)을 입력할 수 있다
- US-003: 사용자는 분석 진행 상황을 실시간으로 확인한다 (진행률, 현재 에이전트)
- US-004: 사용자는 분석 완료 후 구조화된 결과를 TUI에서 읽는다
- US-005: 사용자는 'exit' 또는 'quit' 명령으로 프로그램을 종료한다

### Epic 2: AI 분석 엔진
```
AS A 시스템
I WANT 기존 PRISM-INSIGHT의 모든 분석 에이전트를 활용하여
SO THAT 일관된 품질의 분석 제공
```

**User Stories:**
- US-101: 시스템은 6개 분석 에이전트를 순차적으로 실행한다
  - Technical Analyst (주가/거래량) - GPT-4.1
  - Trading Flow Analyst (투자자 거래 동향) - GPT-4.1
  - Financial Analyst (재무 분석) - GPT-4.1
  - Industry Analyst (산업 분석) - GPT-4.1
  - Information Analyst (뉴스 분석) - GPT-4.1
  - Market Analyst (시장 분석) - GPT-4.1
- US-102: 시스템은 투자 전략 에이전트를 실행하여 종합 전략을 수립한다 (GPT-4.1)
- US-103: 시스템은 요약 에이전트로 핵심 포인트를 추출한다 (GPT-4.1)
- US-104: 시스템은 GPT-5를 활용한 매수/매도 의견을 제공한다
- US-105: 시스템은 Claude 4.1을 활용한 대화형 Q&A를 지원한다

### Epic 3: 투자 보고서 생성
```
AS A 사용자
I WANT 분석 결과가 만족스러울 때만 보고서로 저장하고
SO THAT 불필요한 파일 생성을 방지
```

**User Stories:**
- US-201: 사용자는 분석 결과 확인 후 "보고서 저장할까요?" 프롬프트를 본다
- US-202: 사용자가 'y' 입력 시 마크다운 보고서가 생성된다
- US-203: 사용자가 'n' 입력 시 다음 분석으로 진행한다
- US-204: 보고서는 `reports/tui/{종목코드}_{YYYYMMDD_HHMMSS}.md` 형식으로 저장된다

### Epic 4: 명령어 시스템
```
AS A 사용자
I WANT 다양한 명령어로 프로그램을 제어하고
SO THAT 효율적인 워크플로우 구성
```

**User Stories:**
- US-301: 사용자는 `/help` 명령으로 사용 가이드를 본다
- US-302: 사용자는 `/history` 명령으로 세션 내 분석 이력을 본다
- US-303: 사용자는 `/clear` 명령으로 화면을 지운다
- US-304: 사용자는 `/config` 명령으로 AI 모델 설정을 확인한다
- US-305: 사용자는 `/last` 명령으로 마지막 분석 결과를 다시 본다

## 5. 비기능 요구사항 (Non-Functional Requirements)

### 5.1 성능 (Performance)
- **응답 시간**: 1개 종목 전체 분석 완료까지 3분 이내 (기존 시스템과 동일)
- **동시성**: 단일 사용자 세션만 지원 (멀티 세션 불필요)
- **메모리**: 500MB 이하 (기존 시스템 대비 30% 절감, PDF/차트 생성 최소화)

### 5.2 안정성 (Reliability)
- **에러 복구**: API 실패 시 자동 재시도 (최대 3회)
- **크래시 방지**: 예외 발생 시 프로그램 종료 방지, 에러 로깅
- **데이터 무결성**: 분석 중단 시 임시 데이터 정리

### 5.3 사용성 (Usability)
- **학습 곡선**: 5분 이내 사용법 숙지 가능
- **직관성**: Claude Code와 유사한 UX로 친숙함 제공
- **접근성**: 터미널만 있으면 OS 무관 실행 가능

### 5.4 유지보수성 (Maintainability)
- **모듈화**: 기존 코드 수정 없이 독립 모듈로 구성
- **확장성**: 새로운 명령어/에이전트 추가 용이
- **테스트**: 단위 테스트 커버리지 70% 이상

### 5.5 호환성 (Compatibility)
- **OS**: Linux, macOS, Windows (WSL)
- **Python**: 3.10 이상
- **터미널**: 256색 이상 지원 (True Color 권장)
- **폰트**: Nerd Font 권장 (아이콘 표시)

#### tui/main.py
```python
"""
TUI 메인 진입점
- 프로그램 시작/종료
- 메인 루프 (무한 반복)
- 사용자 입력 처리
- 에러 핸들링
"""

async def main():
    session = TUISession()
    renderer = TUIRenderer()
    adapter = CoreAdapter()

    renderer.show_welcome()

    while True:
        try:
            user_input = await renderer.get_input()

            if user_input in ['/exit', '/quit']:
                break

            if user_input.startswith('/'):
                handle_command(user_input, session, renderer)
            else:
                # 주식 분석
                await analyze_and_display(user_input, adapter, renderer, session)

        except KeyboardInterrupt:
            if renderer.confirm_exit():
                break
        except Exception as e:
            renderer.show_error(e)

    renderer.show_goodbye()
```
