## 1. 소개

### 1.1 PRISM-INSIGHT TUI란?

PRISM-INSIGHT TUI는 터미널 환경에서 실행되는 **AI 기반 주식 분석 도구**입니다.

**주요 기능**:
- 🤖 12개 전문 AI 에이전트의 협업 분석
- 📊 실시간 주식 데이터 수집 및 분석
- 💬 Claude AI와의 대화형 Q&A
- 📝 투자 보고서 자동 생성
- ⚡ Claude Code와 유사한 직관적 UI

### 1.2 누구를 위한 도구인가?

- **개발자**: 코딩하면서 터미널에서 바로 주식 분석
- **퀀트 투자자**: 데이터 기반 투자 의사결정
- **파워유저**: CLI 환경을 선호하는 사용자

### 1.3 시스템 요구사항

- **OS**: Linux, macOS, Windows (WSL)
- **Python**: 3.10 이상
- **터미널**: 256색 이상 지원
- **인터넷**: 필수 (실시간 데이터 수집)

## 2. 시작하기

### 2.1 설치

#### Step 1: 저장소 클론
```bash
git clone https://github.com/yourusername/prism-insight.git
cd prism-insight
```

#### Step 2: TUI 전용 패키지 설치
```bash
pip install -r requirements-tui.txt
```

#### Step 3: API 키 설정
```bash
# .env 파일 생성
cp .env.example .env

# API 키 입력 (편집기로 열기)
nano .env
```

**.env 파일 예시**:
```bash
# OpenAI (GPT-4.1, GPT-5)
OPENAI_API_KEY=sk-your-key-here

# Anthropic (Claude Sonnet 4.5)
ANTHROPIC_API_KEY=sk-ant-your-key-here

# Firecrawl (웹 스크래핑)
FIRECRAWL_API_KEY=fc-your-key-here

# Perplexity (뉴스 검색)
PERPLEXITY_API_KEY=pplx-your-key-here
```

#### Step 4: MCP 서버 설정
```bash
# MCP 설정 파일 복사
cp mcp_agent.config.yaml.example mcp_agent.config.yaml
cp mcp_agent.secrets.yaml.example mcp_agent.secrets.yaml

# secrets 파일에 API 키 입력
nano mcp_agent.secrets.yaml
```

### 2.2 첫 실행

```bash
python -m tui.main
```

또는 간편 실행:
```bash
python run_tui.py
```

```

- 종목코드 입력 (예: 005930)

## 명령어
- /help      : 이 도움말 표시
```

## 6. 팁과 트릭

### 6.1 효율적인 워크플로우

**시나리오 1: 여러 종목 빠르게 분석**
```
1. 삼성전자 입력 → 분석
2. 보고서 저장? n (저장 안 함)
3. Q&A? [Enter] (건너뛰기)
4. SK하이닉스 입력 → 분석
5. 보고서 저장? n
6. /history로 비교
```

**시나리오 2: 심층 분석**
```
1. 삼성전자 입력 → 분석
2. 결과 확인 (스크롤)
3. 보고서 저장? y
4. Q&A로 궁금한 점 질문
   - "경쟁사 대비 어떤가요?"
   - "재무제표 중 주목할 점은?"
   - "리스크는 무엇인가요?"
5. /last로 결과 재확인
```

## 7. 문제 해결

### 7.1 자주 묻는 질문 (FAQ)

#### Q1: "종목을 찾을 수 없습니다" 에러
**원인**: 잘못된 종목 코드 또는 종목명

**해결**:
- 종목 코드는 6자리 숫자 (예: 005930)
- 종목명은 정확히 입력 (예: "삼성전자" ✅, "삼성" ❌)
- KOSPI/KOSDAQ 상장 종목만 지원

#### Q2: 분석이 너무 느려요
**원인**: API Rate Limit 또는 네트워크 지연

**해결**:
- 잠시 기다리기 (자동 재시도)
- 분석은 보통 2~3분 소요
- 네트워크 연결 확인

#### Q3: "MCP 서버에 연결할 수 없습니다" 에러
**원인**: MCP 서버 설정 오류

**해결**:
```bash
# MCP 설정 확인
cat mcp_agent.config.yaml

# 필요한 MCP 서버 설치
# kospi_kosdaq
pip install kospi-kosdaq-stock-server

# firecrawl
npm install -g firecrawl-mcp
```

#### Q4: API 키 오류
**원인**: 잘못된 또는 만료된 API 키

**해결**:
```bash
# .env 파일 확인
cat .env

# API 키 재설정
nano .env
```

### 7.2 에러 메시지 해설

| 에러 메시지 | 의미 | 해결 방법 |
|-------------|------|-----------|
| `종목을 찾을 수 없습니다` | 잘못된 종목 코드/명 | 올바른 종목 코드 입력 |
| `데이터를 가져올 수 없습니다` | API 호출 실패 | 네트워크 확인, 잠시 후 재시도 |
| `MCP 서버에 연결할 수 없습니다` | MCP 서버 오류 | MCP 설정 확인 |
| `API 요청 한도 초과` | Rate Limit | 자동 재시도 대기 |
