## 1. 소개

### 1.1 PRISM-INSIGHT Streamlit이란?

웹 브라우저에서 실행되는 **개인용 AI 주식 분석 도구**입니다.

**주요 특징**:
- 🌐 브라우저만 있으면 어디서나 접근
- 🤖 12개 전문 AI 에이전트의 협업 분석
- 💬 Claude AI와 실시간 Q&A
- 📊 시각적 차트 및 그래프
- 📥 PDF 다운로드 (선택적)

### 1.2 누구를 위한 도구인가?

- **개인 투자자**: 여러 종목 비교 분석
- **직장인**: 점심시간에 빠르게 확인
- **학생**: 투자 공부 및 연구

### 1.3 시스템 요구사항

- **브라우저**: Chrome, Firefox, Safari, Edge (최신 버전)
- **인터넷**: 필수
- **Python**: 3.10 이상 (실행용)

## 2. 시작하기

### 2.1 설치

#### Step 1: 저장소 확인
```bash
cd prism-insight
```

#### Step 2: 의존성 설치
```bash
pip install streamlit>=1.30.0
```

#### Step 3: API 키 설정 확인
```bash
# .env 파일이 있는지 확인
cat .env
```

**.env 예시**:
```bash
OPENAI_API_KEY=sk-your-key
ANTHROPIC_API_KEY=sk-ant-your-key
FIRECRAWL_API_KEY=fc-your-key
PERPLEXITY_API_KEY=pplx-your-key
```

### 2.2 첫 실행

```bash
streamlit run streamlit_apps/personal_analyzer.py
```

또는 간편 스크립트:
```bash
./run_streamlit.sh
```

### 2.3 브라우저에서 접속

실행하면 자동으로 브라우저가 열립니다:
```
You can now view your Streamlit app in your browser.

  Local URL: http://localhost:8501
  Network URL: http://192.168.0.10:8501
```

주소창에 `http://localhost:8501` 입력

## 6. 문제 해결

### 6.1 자주 묻는 질문 (FAQ)

#### Q1: "종목을 찾을 수 없습니다" 에러

**원인**: 잘못된 종목 코드 또는 종목명

**해결**:
- 종목 코드는 6자리 숫자 정확히 입력 (예: `005930`)
- 종목명은 정확한 이름 입력 (예: "삼성전자" ✅, "삼성" ❌)
- KOSPI/KOSDAQ 상장 종목만 지원

#### Q2: 분석이 멈추거나 너무 느림

**원인**: API 호출 지연 또는 네트워크 문제

**해결**:
- 2~3분 정도 기다리기 (정상)
- 5분 이상 걸리면 페이지 새로고침 (F5)
- 인터넷 연결 확인

#### Q3: PDF 다운로드가 안 됨

**원인**: 브라우저 팝업 차단 또는 권한 문제

**해결**:
- 브라우저 팝업 허용
- 다운로드 권한 확인
- Chrome 사용 권장

#### Q4: AI 질문에 답변이 안 옴

**원인**: 분석을 먼저 하지 않음

**해결**:
- 먼저 종목 분석 실행
- 분석 완료 후 질문

### 6.2 에러 메시지 해설

| 에러 메시지 | 의미 | 해결 방법 |
|-------------|------|-----------|
| `분석 실패: API 키 오류` | API 키 문제 | `.env` 파일 확인 |
| `올바른 종목코드를 입력하세요` | 입력 형식 오류 | 6자리 숫자 또는 정확한 종목명 |
| `PDF 생성 중 오류 발생` | PDF 변환 실패 | wkhtmltopdf 설치 확인 |

### 6.3 브라우저 호환성
